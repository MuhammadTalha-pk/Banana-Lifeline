# Banana Lifeline — No Firebase Storage / No Billing Patch

This patch keeps:
- Firebase Authentication
- Cloud Firestore
- Firebase Messaging
- Firebase ID-token verification

It removes Firebase Storage from the runtime flow.

Media flow:
Flutter -> authenticated FastAPI multipart upload -> backend/uploads/
AI/RAG -> Firestore metadata/results

## Apply

Extract this ZIP into:

D:\Hackathon\Banana-Lifeline

Allow overwrite.

Do NOT overwrite or delete:

mobile\lib\firebase_options.dart

That file was generated by `flutterfire configure`.

## 1. Redeploy Firestore rules

```powershell
cd D:\Hackathon\Banana-Lifeline\firebase
firebase use banana-lifeline
firebase deploy --only firestore:rules,firestore:indexes
```

## 2. Create backend .env

```powershell
cd D:\Hackathon\Banana-Lifeline\backend
Copy-Item .env.example .env
notepad .env
```

Set:
- FIREBASE_PROJECT_ID=banana-lifeline
- GOOGLE_APPLICATION_CREDENTIALS=real service-account JSON path
- BANANA_AI_ROOT=friend AI folder
- BANANA_MODEL_CHECKPOINT=real trained checkpoint when available
- DEEPSEEK_API_KEY=real key when generation is enabled
- MEDIA_DIR=./uploads

No fake disease result is used if the real checkpoint is absent.

## 3. Firebase Admin service account

Firebase Console:
Project settings -> Service accounts -> Generate new private key

Save the JSON OUTSIDE Git, for example:

D:\Hackathon\secrets\banana-lifeline-service-account.json

Never commit it.

## 4. Mobile config

```powershell
cd D:\Hackathon\Banana-Lifeline\mobile
Copy-Item .\config\dev.example.json .\config\dev.json
```

Find your PC LAN IPv4:

```powershell
ipconfig
```

If the PC is `192.168.1.25`, use:

```json
{
  "AI_BASE_URL": "http://192.168.1.25:8000",
  "API_PREFIX": "/api/v1"
}
```

Phone and PC must be on the same Wi-Fi for local testing.

## 5. Android cleartext HTTP for local testing only

In:

mobile\android\app\src\main\AndroidManifest.xml

inside `<application ...>` add:

```xml
android:usesCleartextTraffic="true"
```

Use HTTPS in production.

## 6. Start backend

Create/activate your Python venv, install requirements, then:

```powershell
cd D:\Hackathon\Banana-Lifeline\backend
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

Check on the PC:

http://127.0.0.1:8000/api/v1/health

## 7. Run Flutter

```powershell
cd D:\Hackathon\Banana-Lifeline\mobile
flutter clean
flutter pub get
flutter analyze
flutter run --dart-define-from-file=config/dev.json
```

## Important

The backend serves `/media/...` directly for the hackathon so images/audio can be
displayed without paid object storage. UUID filenames make URLs hard to guess, but
this is not a production privacy boundary. For a public production deployment,
replace local media hosting with private object storage or authenticated/signed
media access.
